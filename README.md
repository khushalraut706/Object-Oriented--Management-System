# Object-Oriented-Management-System

A modern and responsive Java Projects Website designed to showcase multiple Java programming projects through an interactive web interface.

The website provides a collection of useful mini-projects, including ATM Banking System, Railway Ticket Fare Calculator, Restaurant Billing System, and Online Shopping Discount Calculator.

It features a clean dashboard with a unique ledger and ticket-stub inspired design.

## 🌟 Features

- Modern and responsive user interface.
- Interactive project dashboard.
- ATM Banking System.
- Railway Ticket Fare Calculator.
- Restaurant Billing System.
- Online Shopping Discount Calculator.
- Real-time calculations using JavaScript.
- Input validation and error handling.
- Dynamic result and receipt generation.
- Responsive navigation.
- Mobile-friendly layout.
- Attractive animations and hover effects.

## 📌 Projects Included

### 1. 🏦 ATM Banking System

A simple ATM simulation that provides basic banking operations.

**Features:**
- PIN verification.
- Check account balance.
- Deposit money.
- Withdraw money.
- Transaction receipt.
- Insufficient balance validation.
- Logout functionality.

**Demo PIN:** `123`

**Starting Balance:** ₹10,000

### 2. 🚆 Railway Ticket Fare Calculator

A ticket fare calculation system that calculates passenger fares based on age and gender.

**Features:**
- Passenger name input.
- Age validation.
- Gender selection.
- Child concession.
- Senior citizen concession.
- Women's concession.
- Automatic fare calculation.
- Fare receipt generation.

**Base Fare:** ₹500

### 3. 🍽️ Restaurant Billing System

A restaurant billing application that calculates the total bill based on selected food items and quantities.

**Features:**
- Food item selection.
- Quantity management.
- Automatic subtotal calculation.
- 10% discount for bills above ₹1,000.
- 5% GST calculation.
- Final bill generation.
- Reset menu functionality.

### 4. 🛍️ Online Shopping Discount Calculator

An online shopping discount calculator that applies discounts based on purchase amount and membership status.

**Features:**
- Customer name input.
- Purchase amount validation.
- Automatic discount calculation.
- Premium membership bonus.
- Final payable amount.
- Discount receipt generation.

**Discount Structure:**

| Purchase Amount | Discount |
|---|---|
| Above ₹1,000 | 5% |
| Above ₹5,000 | 10% |
| Above ₹10,000 | 20% |
| Premium Member | Additional 5% |

## 🔗 APIs Used

**External APIs:** None.

This project does not currently use external REST APIs, third-party APIs, or backend API services.

It uses built-in browser JavaScript functionality:

| JavaScript Function | Purpose |
|---|---|
| `document.getElementById()` | Access HTML elements |
| `document.querySelector()` | Select HTML elements |
| `document.querySelectorAll()` | Select multiple elements |
| `document.createElement()` | Create DOM elements |
| `classList.add()` | Add CSS classes |
| `classList.remove()` | Remove CSS classes |
| `textContent` | Update text content |
| `innerHTML` | Display dynamic receipts |
| `toLocaleString()` | Format currency values |
| `parseFloat()` | Convert input into decimal numbers |
| `parseInt()` | Convert input into integers |

**Note:** These are built-in JavaScript and DOM methods, not external APIs.

## ⚙️ Installation and Setup

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open Project Folder

```bash
cd Java-Projects-Website
```

### Step 3: Open in VS Code

```bash
code .
```

### Step 4: Run the Application

- Open the project in Visual Studio Code.
- Install the Live Server extension.
- Right-click `index.html`.
- Select Open with Live Server.

The website will open in your default browser.

**No backend server or database installation is required.**
